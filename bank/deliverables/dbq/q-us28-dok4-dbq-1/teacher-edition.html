The question

Using BOTH documents and your knowledge of the Red Scare (US.28) and the Sacco and Vanzetti case (US.38), write a multi-paragraph response that analyzes each document using the HIPP framework (Historical context, Intended audience, Purpose, Point of view) and constructs an argument about how anti-radical fear shaped the treatment of immigrants and political dissenters in 1920s America. Your response

  1. analyze both documents using HIPP
  2. identify what each document reveals about its author's perspective and agenda
  3. construct a supported argument using evidence from both documents and your own knowledge

Scoring guide

Pts6-point scale
6Exemplary. Full HIPP analysis of both documents (all four elements for each). Constructs a precise argument about anti-radical repression using evidence from both documents. Incorporates at least two pieces of outside evidence. Analysis addresses both documents' perspective/agenda explicitly.
5Advanced. HIPP analysis of both documents (at least 3 elements each). Constructs a clear argument. Uses evidence from both documents and at least one piece of outside evidence.
4Proficient. HIPP analysis of both documents (at least 2 elements each). Argument present. Uses evidence from both documents.
3Adequate. Analyzes both documents with some HIPP elements. Argument present but underdeveloped. May rely mostly on one document.
2Developing. Some document analysis but HIPP not applied systematically. Argument weak. Limited outside knowledge.
1Beginning. Minimal document engagement. Summary without analysis. No clear argument.
0No response or completely off-topic.
Expected evidence and document analysis. DOCUMENT ANALYSIS EXPECTATIONS: Palmer's pseudo-scientific racial language as evidence of purpose; Vanzetti's dual identity (radical + Italian) as evidence of intersecting persecution; both documents produced in legal/political contexts. KEY EVIDENCE EXPECTED: Palmer Raids, deportations, ACLU, Schenck, Sacco and Vanzetti trial timeline, Judge Thayer, international protests, execution August 23, 1927.
